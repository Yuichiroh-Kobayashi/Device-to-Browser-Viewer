# Archive

This directory holds historical evidence: dated physical-validation narratives,
superseded design prose, and past internal process labels. Every document in
this directory is marked:

```text
HISTORICAL EVIDENCE — NOT CURRENT PRODUCT AUTHORITY
```

Numeric results, PASS/FAIL labels, commit hashes, and browser/OS versions
recorded here are preserved unchanged, even where later current-product docs
describe different or narrower behavior. Do not treat anything in this
directory as a description of current product behavior, current scope, or a
current commitment. For current product behavior, see
[`docs/product/`](../product/). For current AI/agent guidance, see
`AGENTS.md` and `CLAUDE.md` at the repository root.
